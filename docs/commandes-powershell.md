## Github

1. Vérifier l'état
git status

2. Voir les modifications
git diff

3. Ajouter les fichiers
git add .

4. Faire un commit
git commit -m "message"

5. Envoyer sur Github
git push

6. Récupérer de Github
git pull

7. Revenir au dernier commit
git reset --hard HEAD

8. Changer de branche
git checkout main
main = nom de la branche
